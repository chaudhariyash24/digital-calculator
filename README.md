# Digital Calculator

A responsive calculator built with HTML, CSS and JavaScript.

## 🚀 Live Demo
You can access the live deployed application here: **[igital-calculator-live.vercel.app](https://igital-calculator-live.vercel.app/)**

## Features
- Keyboard support
- Responsive design
- AC, DEL, %, +, -, *, /
- Modern UI

## Run
Open index.html in a browser.
